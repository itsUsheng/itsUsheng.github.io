欢迎来到我的博客！

这是使用 **Hexo** 和 **Butterfly** 主题搭建的第一篇文章。

## 如何写新文章

在博客根目录执行：

```bash
hexo n "文章标题"
```

然后编辑 `source/_posts/` 下生成的 Markdown 文件即可。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `hexo s` | 本地预览 |
| `hexo g` | 生成静态文件 |
| `hexo d` | 部署到 GitHub Pages |
